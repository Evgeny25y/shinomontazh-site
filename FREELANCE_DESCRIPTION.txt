================================================================================
КРАТКОЕ ОПИСАНИЕ
================================================================================

Полнофункциональный, отзывчивый веб-сайт для шиномонтажного сервиса.
Современный дизайн с чёрным фоном и красными акцентами. Оптимизирован для
всех устройств (мобильные, планшеты, десктоп). Готов к использованию
и развертыванию на любом хостинге.

================================================================================
ОСНОВНЫЕ ХАРАКТЕРИСТИКИ
================================================================================

✅ HTML5 + CSS3 + Vanilla JavaScript
✅ Полностью отзывчивый дизайн (mobile-first)
✅ Оптимизированные WebP изображения
✅ Форма записи на услугу (готова к интеграции)
✅ SEO-оптимизированная структура
✅ Кросс-браузерная совместимость
✅ Быстрая загрузка (~400KB с изображениями)
✅ Доступность для инвалидов (WCAG)
