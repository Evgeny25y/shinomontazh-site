# ШИНОМОНТАЖ - Сайт шиномонтажного сервиса

Современный, отзывчивый веб-сайт для шиномонтажного сервиса с привлекательным дизайном и функциональной формой записи.

## Особенности

✅ **Отзывчивый дизайн** - адаптируется к любому размеру экрана
✅ **Мобильная оптимизация** - удобно использовать на смартфоне
✅ **Профессиональный вид** - черный фон с красными акцентами
✅ **Быстрая загрузка** - оптимизированные изображения в WebP
✅ **Форма записи** - простая запись на услугу

## Структура сайта

- **Герой** - впечатляющий заголовок с фотографиями
- **Услуги** - 2x2 сетка основных услуг
- **Преимущества** - 4 причины выбрать нас
- **Контакты** - информация и форма записи

## Адаптивность

- **Десктоп** (>1024px): 2-колоночный макет, горизонтальное фото
- **Планшет** (768-1024px): 1-колоночный макет
- **Мобильный** (<768px): оптимизированный вид, вертикальное фото

## Как использовать

1. Откройте `index.html` в браузере
2. Или разверните на GitHub Pages (см. ниже)

## GitHub Pages

Сайт автоматически разворачивается на GitHub Pages.

**URL:** https://evgeny25y.github.io/shinomontazh-site/

### Настройка GitHub Pages

Если Pages еще не активирован:
1. Перейдите в Settings → Pages
2. Выберите Branch: `master`
3. Выберите Folder: `/ (root)`
4. Нажмите Save

Сайт будет доступен по ссылке выше через 1-2 минуты.

## Технологии

- HTML5
- CSS3 (с медиа-запросами для отзывчивости)
- WebP изображения
- Ванильный JavaScript (для взаимодействия)
